# 毕业论文格式校验工具

一个纯前端的论文格式校验工具。上传 `.docx`，自动按规范检查格式问题，**可一键修正并导出新的文档**，全程在浏览器本地完成，论文不上传服务器。

在线试用：<https://aserein66.github.io/thesis-formatter/>
国内备用：<https://c506736a3eac4348b1f90e38df950957.app-tencent.workbuddy.host>
源码仓库：<https://github.com/ASEREIN66/thesis-formatter>

## 它解决什么问题

毕业论文的格式要求细碎且各校不同——页边距、行距倍数、标题字号、首行缩进字符数、参考文献标点……人工逐项核对既慢又容易漏。这个工具把这些要求拆成**可开关、可改期望值**的检查项，一次跑完，并按「必须修改 / 建议修改」分级给出清单。

## 功能

- **15 条格式检查项**，分 5 组：页面设置、正文、标题、参考文献（GB/T 7714）、标点与排版
- **论文内容预览**：逐段显示原文，问题段落标色条并在下方写明原因，可从问题项一键定位
- **可真正改文档**：支持逐条修正与一键修正，改完导出 `原名-已修正.docx`，原文件不动
- **规则自动抽取**：粘贴或上传学校的《撰写规范》，自动抽出候选规则并附「依据原文片段」，逐条确认后才生效。两种方式可选：本地正则匹配（不联网、不耗 token）或调用大模型接口（能读懂同义表述与表格）
- **检查报告**：点开即预览全文，可一键复制或下载 `.md` / `.txt`，内容含已修正清单、剩余问题、本次使用的规范参数表
- **文档管理**：传错了一键移除重来，不用刷新页面

## 设计要点

**规则项与参数值分离。** 规则项（检查什么）是全国通用的，参数值（期望多少）才是本校的。所以换学校时不用重写规则引擎，只改参数。

**抽取 + 人工确认闭环。** 不假装自动抽取全对——每条候选规则都附依据原文片段和置信度标签，抽错了能一眼看出来。

**检测—修正—导出闭环。** 不只是"报问题"，是能闭环解决。

## 技术实现

- 直接解析 docx 的 OOXML（解 zip 读 XML），比走 Office 接口更准——页码格式、尾注这类信息接口读不出语义
- 字号、行距、缩进做了三级回退（段落直接格式 → run 格式 → 样式定义），段落没显式设置时不会误报
- **零依赖**：用浏览器原生的 `DecompressionStream` / `CompressionStream` 自己实现了 ZIP 读写，另带一个纯 JS 解压兜底，不加载任何外部库
- 单个 HTML 文件 87 KB，双击即用，可离线

## 隐私

论文全文只在你自己的浏览器里解析，不发送至任何服务器。线上版本同理——托管的只是工具页面本身。

## 本地使用

直接下载 `index.html`，用 Chrome / Edge / Safari 打开即可，无需联网、无需安装。

需要较新版本的浏览器（用到原生解压接口）；如遇老浏览器，代码会自动回退到内置的纯 JS 解压实现。
